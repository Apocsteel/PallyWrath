# Pally Wrath

*by ApocSteel — WoW Forever (1.60.x)*

Shows your **Unsealed Wrath** echo stacks (Echo of Command, Echo of Righteousness, Echo of Wisdom, Echo of Light, Echo of Justice, Echo of Fury) right next to your character.

## Features
- **Three styles:** golden crescent, sword, or the game's own 3D model.
- Fills in **thirds** with each stack, colored by the stored seal.
- At **3 stacks** it bursts into flames, shows a timer and plays a sound.
- **Works in combat.**
- Four fill directions, mirrored copy, opacity, size, colors and position.
- English and Spanish.

## Requirement
Keep the **Unsealed Wrath** icon in Blizzard's buff tracker (Cooldown Manager → Tracked Buffs). In combat the game hides buff data from add-ons; Pally Wrath counts stacks from that icon. Pally Wrath turns the Cooldown Manager on if needed and, by default, makes the buff tracker invisible while keeping it active (`/pw tracker` to show it again).

## Commands
- `/pw` — options menu
- `/pw help` — command list
- `/pw test` — preview
- `/pw unlock` / `/pw lock` — move the indicator

# Pally Wrath (español)

Muestra las cargas de los ecos de **Unsealed Wrath** junto a tu personaje: media luna, espada o modelo 3D que se rellena por tercios, toma el color del sello y arde con 3 cargas.

**Requisito:** deja el icono de **Unsealed Wrath** en el visor de buffs de Blizzard (Gestor de reutilizaciones → Beneficios rastreados). En combate el juego oculta los buffs a los addons y Pally Wrath cuenta las cargas con ese icono. El addon activa el Cooldown Manager si hace falta y, de base, deja el visor invisible pero activo (`/pw visor` para volver a verlo).

**Comandos:** `/pw` (opciones), `/pw ayuda`, `/pw test`, `/pw mover` / `/pw fijar`.
